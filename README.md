# LeetCode Solutions

个人 LeetCode 刷题记录，使用 PyCharm + LeetCode Editor 插件维护。

## 目录结构

```
leetcode-solutions/
├── solutions/          # 题目代码（插件 Temp File Path 指向这里）
├── .gitignore
└── README.md
```

## 环境配置

PyCharm 中 LeetCode Editor 插件的关键设置：

| 设置项 | 值 |
| --- | --- |
| URL | `https://leetcode.cn` |
| Temp File Path | `<本仓库绝对路径>/solutions` |
| 语言 | Python3 |
| Code FileName | `$!{question.frontendQuestionId}-$!{question.titleSlug}` |

> Temp File Path 必须落在 PyCharm 当前打开的项目目录内，否则编辑器右上角的 Run / Submit 按钮不会出现。
